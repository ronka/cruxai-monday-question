# Interview starter base

Shared base for the feature-implementation interview starters. Each question lives on its own `codex/<product>-<feature>-starter` branch.

- `src/mock/sqlite.ts` — browser SQLite (sql.js) persisted to IndexedDB.
- `src/mock/clock.ts` — controllable mock clock.
- `src/mock/network.ts` — latency and one-shot failure / lost-response injection.
- `src/mock/events.ts` — typed emitter for live updates.
- `src/mock/MockControls.tsx` — floating panel for mock controls.
